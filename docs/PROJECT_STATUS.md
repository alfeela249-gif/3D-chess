# 3D Chess — Project Plan

## Goal
Build an Android APK for two players on the same Wi-Fi network, without requiring internet or cloud services.

## Planned implementation
- Native Android application in Kotlin.
- 3D chessboard and pieces rendered with OpenGL ES.
- Complete chess rules and legal move validation.
- Local multiplayer using a TCP connection over Wi-Fi.
- GitHub Actions workflow to build and publish a debug APK artifact.

## Current status
Repository write access has been tested. This file records the project scope; the application source and APK build pipeline are the next implementation steps.
